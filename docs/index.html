E-Reader Patent Sleep Screens

GitHub

Sleep screens made from old patent drawings in the public domain, taken from Wikimedia Commons. The images are line drawings reduced to 4 gray levels (2 bits per pixel), so they suit e-ink screens. They work with CrossPoint, KOReader, and any e-reader that can show a custom image as its sleep screen.

Other screen sizes

For a different screen, open an issue with the model, the screen size in pixels (width × height, portrait) and the image format its sleep screen accepts.

The drawings are in the public domain; each card links to its source page on Wikimedia Commons. The generator script is MIT licensed and the processed images are released under CC0. Not affiliated with CrossPoint, KOReader or Amazon.
